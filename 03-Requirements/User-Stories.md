# User Stories

## US-001 — Submit Loan Application

As a customer,

I want to submit my personal loan application online,

so that I can apply without visiting a bank branch.

### Acceptance Criteria

- Customer can enter required personal information.
- Customer can enter requested loan amount.
- Customer can select loan duration.
- Mandatory fields must be validated.
- Customer can submit the application.
- Application reference number is generated.

---

## US-002 — Upload Documents

As a customer,

I want to upload my required documents,

so that the bank can verify my application.

### Acceptance Criteria

- Customer can upload supported document formats.
- Mandatory documents must be identified.
- Invalid files should generate an error.
- Customer can see uploaded documents.
- Successful uploads should be confirmed.

---

## US-003 — Track Application

As a customer,

I want to see my loan application status,

so that I know the current progress of my application.

### Acceptance Criteria

- Customer can view application status.
- Status should show the current processing stage.
- Status should include last updated date.
