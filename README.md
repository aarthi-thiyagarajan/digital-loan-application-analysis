# Digital Loan Application Analysis

## Business Analysis Portfolio Project

### Project Overview

This is a simulated Business Analyst project focused on improving
the digital personal loan application and approval process for a
retail banking organization.

### Business Problem

The bank is experiencing:

- Long loan approval times
- High manual processing
- Delays in document verification
- Customer application abandonment
- Limited visibility into application status

### Project Objectives

The objective is to:

- Analyze the existing loan application process
- Identify process bottlenecks
- Define business and functional requirements
- Design an improved To-Be process
- Analyze loan application data
- Define UAT scenarios
- Provide business recommendations
